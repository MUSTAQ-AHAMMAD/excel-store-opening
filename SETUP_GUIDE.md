# Setup Guide for Store Opening Event Planner

This guide provides step-by-step instructions to fix the XLSM format issue and set up the Store Opening Event Planner.

## Table of Contents
1. [Prerequisites](#prerequisites)
2. [Fixing the XLSM Format Issue](#fixing-the-xlsm-format-issue)
3. [Setting Up the Event Planner](#setting-up-the-event-planner)

## Prerequisites
- Ensure you have Microsoft Excel installed.
- Download the latest version of the Store Opening Event Planner from the repository.
- Familiarity with the XLSM file format and Excel macros.

## Fixing the XLSM Format Issue
1. **Open the XLSM file in Microsoft Excel.**  
   1.1 Double-click the file or open it through Excel's "File > Open".

2. **Check for Compatibility Mode.**  
   2.1 If the file opens in Compatibility Mode, save it as an XLSM file.  
   2.2 Go to "File > Save As" and select "Excel Macro-Enabled Workbook (*.xlsm)".

3. **Resolve any Macro Security Settings.**  
   3.1 Go to "File > Options > Trust Center > Trust Center Settings > Macro Settings".  
   3.2 Choose "Enable all macros" (not recommended, change back after testing).

4. **Test the Macros.**  
   4.1 Go to the developer tab (if not visible, enable it in "Options > Customize Ribbon").  
   4.2 Click on "Macros", select one, and click "Run" to ensure it works as intended.

## Setting Up the Event Planner
1. **Open the Store Opening Event Planner workbook.**

2. **Customize the Event Details.**  
   2.1 Update the event name, date, and location in the provided fields on the main sheet.

3. **Add Participants.**  
   3.1 Navigate to the "Participants" sheet.  
   3.2 Enter the names and contact information of attendees.

4. **Set Up the Agenda.**  
   4.1 Go to the "Agenda" sheet.  
   4.2 Fill in the schedule with each session, including titles and times.

5. **Update Budgets.**  
   5.1 Go to the "Budget" sheet and enter anticipated costs and funding sources.

## Testing the Setup
1. **Review all sheets for accuracy.**  
   - Ensure all details are correctly filled.
2. **Run a test of the entire planner.**  
   - Go through the event process to verify all macros and functionalities work.
3. **Save your changes.**  
   - Go to "File > Save" to ensure everything is saved correctly.

## Conclusion
You are now ready to use the Store Opening Event Planner effectively! If you encounter any issues, consult the FAQ or reach out to the support team for assistance.
